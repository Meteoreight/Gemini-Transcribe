# Gemini Transcribe

Google の Gemini API を使用したリアルタイム音声認識アプリケーションです。このElectronベースのデスクトップアプリケーションは、リアルタイムデスクトップ音声キャプチャ、マイク入力、バッチファイル処理など、複数の音声認識モードをサポートしています。

[English](README.md) | **日本語**

## 機能

### 🎵 リアルタイムデスクトップ音声認識
- デスクトップ音声をリアルタイムでキャプチャして文字起こし
- システム全体の音声モニタリングをサポート
- タイムスタンプ付きのライブ転写表示
- 設定可能な音声チャンクと処理

### 🎤 マイク音声認識
- マイク入力からの直接音声認識
- 音声デバイスの選択とテスト
- リアルタイム音声レベルモニタリング
- 音声アクティビティ検出

### 📁 バッチファイル処理
- 複数の音声フォーマットをサポート（MP3, WAV, M4A, FLAC, OGG, AAC）
- ドラッグ＆ドロップファイルインターフェース
- 進捗トラッキング付きバッチ処理
- メタデータ抽出と検証

### ⚙️ 高度な設定
- 複数の出力フォーマット（VTT, SRT, プレーンテキスト）
- 言語検出と翻訳
- 設定可能な処理パラメータ
- セキュアなAPIキー管理

## はじめに

### 必要な環境

Gemini Transcribeをインストールする前に、以下がシステムにインストールされていることを確認してください：

#### 必要なソフトウェア
- **Node.js**（v16以上）- [nodejs.orgからダウンロード](https://nodejs.org/)
- **npm**（Node.jsに含まれています）または **yarn**（オプション）
- **Git** - [git-scm.comからダウンロード](https://git-scm.com/)

#### Google Gemini APIアクセス
- Google Cloud Platformアカウント
- Gemini APIアクセスとAPIキー

**前提条件の確認：**
```bash
# Node.jsのバージョン確認
node --version  # v16.0.0以上である必要があります

# npmのバージョン確認
npm --version   # 8.0.0以上である必要があります

# Gitのインストール確認
git --version
```

### ステップバイステップインストールガイド

#### 1. リポジトリのクローン
```bash
# GitHubからクローン（実際のリポジトリURLに置き換えてください）
git clone https://github.com/your-username/gemini-transcribe.git

# プロジェクトディレクトリに移動
cd gemini-transcribe

# 正しいディレクトリにいることを確認
ls -la  # package.json, src/, docs/ などが表示されるはずです
```

#### 2. 依存関係のインストール
```bash
# 必要なNode.jsパッケージをすべてインストール
npm install

# Electronやその他の依存関係をダウンロードするため、数分かかる場合があります
# 完了時に "added XXX packages" と表示されます
```

#### 3. 環境変数の設定
```bash
# 環境変数サンプルファイルをコピー
cp .env.example .env

# お好みのテキストエディタで.envファイルを開く
# 例：
nano .env
# または
code .env  # VS Codeを使用している場合
```

`.env`ファイルを編集して設定を行います：
```env
# 必須：あなたのGemini APIキー
GEMINI_API_KEY=your_actual_api_key_here

# オプション：その他の設定のカスタマイズ
GEMINI_MODEL=gemini-2.5-flash
DEFAULT_CHUNK_DURATION=5
DEFAULT_OUTPUT_FORMAT=vtt
```

#### 4. アプリケーションのビルド
```bash
# TypeScriptをコンパイルしアセットを準備
npm run build

# コンパイル成功を示す出力が表示されるはずです
# dist/ディレクトリがコンパイルされたファイルと共に作成されます
```

#### 5. インストールのテスト
```bash
# 開発モードでアプリケーションを起動
npm run dev

# Gemini Transcribeウィンドウが開くはずです
# 成功すれば、タブ付きのアプリケーションインターフェースが表示されます
```

### 初回起動設定

#### 初期設定
1. **アプリケーション起動**：初回に`npm run dev`を実行すると、Gemini Transcribeウィンドウが開きます
2. **設定の構成**：
   - 「設定」タブをクリック
   - まだ設定していない場合は、Gemini APIキーを入力
   - 好みのモデルを選択（初心者にはGemini 2.5 Flashを推奨）
   - 出力ディレクトリを設定（デフォルト：~/Documents/Transcriptions）
   - 出力フォーマットを選択（VTT、SRT、またはプレーンテキスト）
3. **権限設定**：
   - **macOS**：デスクトップ音声キャプチャ用の画面録画権限を許可
   - **Windows/Linux**：マイクの権限が有効になっていることを確認
   - **すべてのプラットフォーム**：プロンプトが表示されたときにマイクへのアクセスを許可

#### すべてが動作することを確認
1. **マイクテスト**：
   - 「音声認識」タブに移動
   - マイク選択の横にある「テスト」ボタンをクリック
   - 話すと音声レベルバーが動くのを確認
2. **設定テスト**：
   - 「設定」タブに移動
   - 「設定を保存」をクリック
   - 「設定が保存されました」の確認メッセージが表示される

### インストールのトラブルシューティング

#### よくある問題と解決方法

**❌ "node: command not found"**
- [nodejs.org](https://nodejs.org/)からNode.jsをインストールしてください
- インストール後にターミナルを再起動してください

**❌ "npm install"が権限エラーで失敗する**
- macOS/Linux：`sudo npm install`を使用（推奨されません）またはnpmを適切に設定
- より良い解決策：nvm（Node Version Manager）を使用してNode.jsをインストール

**❌ "Cannot find module 'electron'"**
- すべての依存関係がインストールされていることを確認するため`npm install`を実行
- 必要に応じて`node_modules/`を削除して`npm install`を再実行

**❌ アプリケーションウィンドウが開かない**
- エラーメッセージについてターミナルを確認
- `npm run dev`の前に`npm run build`を実行していることを確認
- `npm run clean && npm run build && npm run dev`を試してください

**❌ "API key invalid"エラー**
- `.env`ファイル内のAPIキーが正しいことを確認
- Google CloudプロジェクトでGemini APIが有効になっていることを確認
- APIキーの周囲に余分なスペースや引用符がないことを確認

#### ヘルプを得る
ここでカバーされていない問題が発生した場合：
1. 下記の[トラブルシューティング](#トラブルシューティング)セクションを確認
2. 具体的なエラーメッセージについてターミナルの出力を確認
3. すべての前提条件が適切にインストールされていることを確認
4. クリーンなディレクトリからインストール手順を再度試してください

## 使用方法

### リアルタイムデスクトップ音声認識

1. 「リアルタイム音声認識」タブに移動
2. 入力言語と出力言語を設定
3. 「録音開始」をクリックしてデスクトップ音声キャプチャを開始
4. プロンプトが表示されたら画面録画権限を許可
5. 文字起こしされたテキストがリアルタイムで表示されます
6. 「録音停止」をクリックしてセッションを終了

### マイク音声認識

1. 「音声認識」タブに移動
2. 音声ソースドロップダウンからマイクを選択
3. 「テスト」ボタンを使用してマイクをテスト
4. 出力言語の設定を構成
5. 「録音開始」をクリックして文字起こしを開始
6. マイクに向かって話す
7. リアルタイムの文字起こし結果を確認

### ファイル処理

1. 「ファイル音声認識」タブに移動
2. 音声ファイルをドラッグ＆ドロップするか、クリックしてブラウザから選択
3. 出力言語設定を構成
4. 「ファイルを処理」をクリックしてバッチ文字起こしを開始
5. 処理進捗を監視
6. 設定された出力ディレクトリで結果にアクセス

### 設定の構成

1. 「設定」タブに移動
2. Gemini APIキーを入力
3. 処理パラメータを設定：
   - モデル選択（Gemini 2.5 Flash、Gemini 1.5 Pro）
   - 音声処理のチャンク時間
   - 出力ディレクトリとフォーマット
   - 自動保存設定
4. 「設定を保存」をクリックして変更を適用

## API設定

このアプリケーションは音声認識処理にGoogle のGemini APIを使用します。以下が必要です：

1. Google Cloudプロジェクトの作成
2. Gemini APIの有効化
3. APIキーの生成
4. アプリケーション設定でのキーの構成

### サポートされているモデル

- **Gemini 2.5 Flash**：高速処理、リアルタイムアプリケーションに適している
- **Gemini 1.5 Pro**：高精度、バッチ処理に適している

## 音声要件

### サポートされている入力フォーマット
- MP3
- WAV
- M4A
- FLAC
- OGG
- AAC

### 音声品質の推奨事項
- サンプルレート：16kHz以上
- ビット深度：最低16ビット
- 背景ノイズを最小限に抑えたクリアな音声
- ファイルあたりの最大サイズ：150MB

## キーボードショートカット

- `Ctrl/Cmd + O`：音声ファイルを開く
- `Ctrl/Cmd + ,`：設定を開く
- `Ctrl/Cmd + Q`：アプリケーションを終了
- `Space`：録音開始/停止（設定可能）

## トラブルシューティング

### 権限の問題

**デスクトップ音声キャプチャ（macOS）**：
- システム環境設定 > セキュリティとプライバシー > プライバシー > 画面収録に移動
- アプリケーションの権限を有効にする

**マイクアクセス**：
- システム設定でマイクの権限が許可されていることを確認
- 正しい音声デバイスが選択されていることを確認

### APIの問題

**認証エラー**：
- APIキーが正しいことを確認
- Google CloudプロジェクトでGemini APIが有効になっていることを確認
- 十分なAPI使用量があることを確認

**レート制限**：
- API呼び出し頻度を減らすためにチャンク時間を短縮
- Google CloudコンソールでのAPI使用量を確認

### 音声処理の問題

**音声が検出されない**：
- 音声デバイスの接続を確認
- システム音声がミュートされていないことを確認
- 異なる音声ソースでテスト

**文字起こし品質が悪い**：
- クリアな音声入力を確保
- 背景ノイズを減らす
- 異なるモデルを試す（より高い精度のためにGemini 1.5 Pro）
